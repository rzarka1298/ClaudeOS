# UAT audit fixtures

Miniature, synthetic copies of each live-UAT evidence format, used only by `uat-audit.test.ts`.
Every title, result and name here is made up for the test: nothing is copied from a real phase file,
and nothing names a person, a path or a project. Never paste a real phase file into this folder.

The folder names (`01-alpha`, `02-beta`, ...) only need to start with the phase number; the checker
finds a phase by that prefix.
